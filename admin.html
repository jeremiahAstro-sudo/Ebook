Export your ready-to-deploy website

This admin tool packages the current books and pass settings into a JSON file for your site. Since GitHub Pages is static, this button cannot directly commit files to GitHub without a separate trusted publishing service. Export the library data, then upload the project files to your repository to deploy.

Quick deployment checklist

  1. Download the project ZIP from the project handoff.
  2. Extract it and replace data/library.json with your exported library data.
  3. Upload the project files to your GitHub repository.
  4. In GitHub, open Settings → Pages and select deploy from your main branch and root folder.
  5. Wait for the Pages deployment to finish, then open the published URL.

This checklist is a manual fallback, not automatic publishing. To make the Publish button commit and deploy directly, a GitHub Actions workflow with a secure trigger or a small trusted service must be configured.
